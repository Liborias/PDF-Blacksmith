# START — nový agent ChatGPT / PDF Blacksmith
Pokračuj ve vývoji PDF Blacksmithu (Liborias/PDF-Blacksmith). Použij GitHub konektor, pracovní větev `chatgpt/ui-review`. Začni aktuální verzí [HANDOFF.md](HANDOFF.md) na této větvi, nikoliv kopií z main ani starou pamětí chatu. Zkontroluj aktuální HEAD, změny Codexu a případné běžící sestavení. Pak načti [AGENTS.md](../../../AGENTS.md) a závazné v6.0 dokumenty dle [CODEX_START.md](../CODEX_START.md). Pracuj pouze na schváleném následujícím kroku; „ok“ platí pro poslední konkrétní návrh. Po každém kroku ulož předání, čítač, výsledky testů a návrh dalšího kroku. První EXE po kroku 1, potom po každých 4 krocích (5, 9, 13…). Žádné automatické vydávání, merge ani změny Codexovy větve. Rozhraní má přednost, F1 je pozastaveno. Nic nezačínej znovu pouze kvůli novému chatu.
