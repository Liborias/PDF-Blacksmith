# Formuláře F1 – schválená rozhodnutí 21. 11. 2026

| ID | Rozhodnutí |
|---|---|
| F-Q1 | **A:** postupně F1 (vyplnit/uložit), pak teprve F2 (tvorba) a F3 (zploštění). |
| F-Q2 | **A:** po detekci formuláře nabídnout přechod do Formulářů, **automaticky nepřepínat**. |
| F-Q3 | **A s podmínkou:** vyplňovat pouze v aktivním Formuláře → Vyplnit; při F2 nabídnout typografická nastavení srovnatelná s nástrojem Text; F1 respektuje vzhled daný formulářem. |
| F-Q4 | **A:** jemné vínové zvýraznění vyplnitelných polí s přepínačem; pouze UI. |
| F-Q5 | **A:** sbalitelný přehled formulářových polí v pravém panelu a klikací navigace. |
| F-Q6 | **A:** seznam řadit podle stran a umístění; **pořadí Tab zachovat nezávisle** dle PDF. |
| F-Q7 | **A:** upozornit na chybějící povinné údaje, ale **Uložit přesto** zůstává možné; AutoRecover neblokovat. |
| F-Q8 | **A:** stav polí aktualizovat průběžně, formátové chyby oznámit až po opuštění pole, souhrn při ukládání. |
| F-Q9 | **A:** chybné pole po opuštění jemně červeně orámovat na stránce i označit v seznamu; po opravě odstranit; netisknout a nezapisovat do PDF. |

**Stav:** F1 schváleno k postupnému vývoji, F2 a F3 nadále pouze plán.
